# Youth Sports Playing Time Tracker

## Overview
This project is a simple yet sophisticated web-based application designed to help coaches and assistants track playing time for youth soccer and basketball teams. It provides an intuitive interface to manage player rosters, track game time, and visually represent player positions on the field or court.

## Features
- Coach-protected access via passcode gate
- Support for Soccer and Basketball with relevant positions
- Real-time game clock with play/pause/reset functionalities
- Dynamic roster management: add/remove players, toggle playing/on bench/injured
- Injury status tracking with alerts
- Visual layout of player positioning on field/court
- Developer mode with seed data for testing

## Technology Stack
- Frontend: Vanilla JavaScript, HTML, CSS with responsive and accessible design
- Stateless client-side architecture for easy customization and portability

## Roadmap and Future Enhancements
- **Backend Integration:**
  - Persistent data storage for rosters, game history, and analytics
  - Multi-user sync for coach and assistants
- **Enhanced UX and Analytics:**
  - Injury/foul tracking and alerts
  - Playtime distribution charts and progress tracking
  - Game reports export/print
- **Mobile and PWA Support:**
  - Touch-optimized interactions
  - Offline capabilities and installable app
- **User Roles and Permissions:**
  - Role-based views for coaches, assistants, and parents
- **External Integrations:**
  - Official schedules, player stats, league APIs
